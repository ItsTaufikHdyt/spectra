## a. Ringkasan eksekutif

1. Aplikasi berjalan: 15 kelurahan tampil sebagai 3D Tiles, UI tiga area, layer batas dan sungai, panel Data geoportal, mode tampilan hemat GPU. Tes lulus (frontend 17/17, backend 20/20, adapter data lulus) dan build sukses [V].
2. **Risiko 1 (kritis, data):** tile hanya memuat 47.108 bangunan, padahal data mentah berisi ±51.883 bangunan unik. ±4.775 bangunan (9,2%) hilang di 4 kelurahan (Gunung Elai 1.897, Bontang Lestari 1.444, Belimbing 1.347, Loktuan 87) karena file gabungan dibuat berdasarkan ID nomor urut yang saling menimpa. `STATUS.md` #7 menyatakan sebaliknya ("tidak ada bangunan hilang") dan **keliru** [V].
3. **Risiko 2 (kritis, simulasi):** simulasi banjir belum punya prasyarat utama. Tidak ada DTM di proyek, tidak ada atribut bangunan sama sekali (0 dari 37 file CityJSON), ID bangunan tidak stabil, dan ketinggian dasar bangunan hanya relatif terhadap tanah [V].
4. **Risiko 3 (tinggi, keberlanjutan):** repo hanya lokal (tanpa remote), data mentah dan tile di-ignore git, dan skrip ETL 01–03 tidak ada di repo. Kerusakan disk berarti kehilangan seluruh hasil konversi. Backend juga tanpa autentikasi [V].
5. Dokumentasi tertinggal: `STATUS.md` masih menulis backend "belum dimulai", empat bagian "belum di-commit", dan jumlah tes lama; README frontend masih berisi instruksi zip [V].
6. Sepuluh temuan audit awal: 4 selesai, 5 sebagian, 1 belum (tabel c).
7. Yang belum bisa diperiksa: CityGML (tidak ada di repo), DTM di luar repo, lint (eslint dan ruff tidak terpasang), performa di GPU NVIDIA, layout layar sempit.

### E4. Backend dan akses
- **Autentikasi/hak tambah-hapus layer:** belum ada; pilih tanpa login (jaringan internal), peran sederhana, atau SSO.
