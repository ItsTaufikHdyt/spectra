# Frontend Digital Twin Kota Bontang

Aplikasi frontend Web 3D GIS berbasis **Vue 3**, **Vite**, dan **CesiumJS** untuk visualisasi Kota Bontang.

## Cara Menjalankan Project

1. Pastikan Node.js (v18+) sudah terpasang.
2. Ekstrak file zip ini ke folder project Anda.
3. Install dependensi:
```bash
npm install
```
4. Jalankan mode development:
```bash
npm run dev
```
5. Buka browser di `http://localhost:3000`.
